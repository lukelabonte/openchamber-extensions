# openchamber-extensions
A place for my OpenChamber extensions

## Development

The extension code lives in `firstmate/`. See [the FirstMate guide](firstmate/README.md) for installation, commands, settings, and port limitations. [Bun](https://bun.com) must be installed to run the tests: from `firstmate/`, run `bun install --frozen-lockfile` for dependencies, then `bun test` (the package script is `test: bun test tests/`).
